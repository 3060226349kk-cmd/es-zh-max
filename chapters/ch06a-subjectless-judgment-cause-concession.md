# 第六章（上）句型：无主句 · 判断句 · 因果复句 · 转折让步复句（原书 p.257–286）

## 核心
翻译不要求句子类型一致。汉语无主句在西语里要有人称或用无人称手段；「是」字判断句要看甲乙是什么关系，再选动词；因果、转折、让步复句要选准关联词，汉语成对的关联词在西语里只能取一个，还常常可以压成单句。**西译中反过来**：西语的 se、uno、quien、hay que 往往正好对应汉语无主句；西语五花八门的系动词多半还原成「是」；关联词能省则省，但「虽然」和「即使」（事实让步还是假设让步）绝不能混。

## 框架
### 1. 无主句（第一节）
三类：
1. **省略主语**（当面对话、命令请求、书信日记、承上省略）：西语也不说主语，但动词变位必须表明人称。几时到的？→ ¿Cuándo llegaste?；刚下火车 → Acabo de bajarme del tren；进来吧，请坐 → Pase y siéntese, por favor。
2. **日常用语**（下雪了、刮风了、行、休想）：自然现象在西语里是单一人称句，不难译。
3. **主语泛指**（没有调查就没有发言权），重点在这一类，五种译法：
   - se 无人称句或自复被动句：如果这样做，那就要犯绝大的错误 → se incurriría en un craso error；东张西望，道听途说，得不到完全的知识 → De ninguna manera se puede adquirir…
   - 泛指主语 uno、tú、nosotros、el que、quien、nadie：只有做群众的学生才能做群众的先生 → Sólo haciéndose discípulos de las masas podrá uno… / Sólo el que se haga discípulo… / Nadie podrá… a menos que…；没有调查就没有发言权 → Quien no ha investigado no tiene derecho a opinar；多行不义必自毙 → Quien comete muchas injusticias busca su propia ruina。
   - 第三人称复数无人称句（只用于施事者不明确，不用于泛指）：已经打铃了 → Ya han tocado el timbre；不卖票了 → ya no venden entradas。
   - 助动词无主句（要、应该、必须、可以）用 haber que + inf. 或 ser + adj. + inf.：要正确处理改革、发展、稳定的关系 → Hay que tratar correctamente…；应积极推进 → Es preciso impulsar…；必须优先发展教育 → Es indispensable dar prioridad…
   - 选句中合适的名词作主语：在生产中，必须实行男女同工同酬 → hombres y mujeres deben recibir igual remuneración por igual trabajo；对于非马克思主义思想，应该采取什么方针？→ ¿Cuál debe ser nuestra política con respecto a…?

### 2. 判断句「甲是乙」（第二节）
先分析甲乙关系，再选动词。多几种译法，也能避免老是重复 ser：
1. 同一事物、归类 → ser：十月一日是国庆节；地球是行星；失败是成功之母。
2. 构成、可以看作 → constituir：石油是委内瑞拉的主要矿物资源 → constituye；和平与发展是当今时代的主题 → constituyen。
3. 意味着 → significar、suponer、implicar、equivaler a、querer decir：消灭敌人，就是解除敌人的武装 → significa desarmarlas, y no quiere decir aniquilarlas…
4. 代表、体现 → representar、encarnar：这是毫无自私自利之心的精神 → Esto encarna…；贪污腐化是消极因素 → Representa un factor negativo。
5. 乙具体说明甲的内容 → consistir en、radicar en、estribar en、residir en：问题是缺少资金 → El problema radica en la falta de fondos；任务是正确处理矛盾 → consiste en…
6. 起作用 → servir de：共同纲领……同时也是一种约束 → servirá de atadura。
7. 结论性的「这就是……」→ He aquí / He ahí：这就是我们肩负的责任 → He ahí la responsabilidad que pesa sobre nuestros hombros。
8. 评论性的「这是……」→ Se trata de：这是一场十分艰巨的斗争 → Se trata de una lucha sumamente ardua。
9. 其他动词：甲的特点是 → se caracteriza por；甲的基础是 → se basa en；法律是上层建筑 → forma parte de la superestructura；社会主义社会是一个很长的历史阶段 → cubre una etapa…；事变是……的开始 → marcó el comienzo de…
10. 「甲是……的」：
   - 是＋形容词或名词＋的：ser + adj.、ser + de + sust.。
   - 是＋动词＋的：多半去掉「是」「的」直接作动词谓语：人民的国家是保护人民的 → El Estado popular protege al pueblo；国家的法律是人人必须遵守的 → Toda persona debe acatar la ley del Estado；最后的胜利是属于中华民族的 → pertenecerá a…
   - 也可以用名词谓语：困难是可以克服的 → son superables；我们是主张自力更生的 → Somos partidarios de… / Nos pronunciamos por…

### 3. 因果复句（第三节）
汉语常「因为……所以……」成对用；西语只能用表因或表果的一方，不能并用。
- 表因：由因及果用 como（放句首）；由果溯因用 porque、pues；推论色彩强的两可用 dado que、puesto que、ya que。
- 表果：y así、así (es) que、conque、en consecuencia、por consiguiente、por ende、por eso、por (lo) tanto、por esta razón。
- 同一句可有两种形式：因为我们是为人民服务的，所以不怕批评 → Servimos al pueblo y por eso no tememos… / Puesto que servimos al pueblo, no tememos…
- 有时只能取一种：你既然不抽烟了，把烟斗给我吧 → Puesto que ya no fumas, dame tu pipa；不能因为是老朋友……就违反规定 → No debemos infringir las disposiciones porque se trate de un viejo amigo…（porque 加虚拟式）。
- **压成单句**：
  - 前置词（短语）＋名词或不定式：de、por、debido a、gracias a、merced a、a causa de、a consecuencia de、como resultado de、en razón de、en virtud de、en vista de、por efecto de。例：不要因为一个人犯了错误就否定他的一切 → No hay que descalificar completamente a alguien por el hecho de haberlos cometido；由于蒋汪叛变，第一次国共合作破裂 → a consecuencia de la traición de…
  - 副动词或过去分词：因为我们是马克思主义者，是不怕批评的 → Siendo marxistas, no tememos a la crítica；既然是半殖民地半封建的性质 → Dada la naturaleza semicolonial y semifeudal…（简练，但因果不如关联词明确）。

### 4. 转折复句与让步复句（第四节）
- 转折以事实为前提：但是、可是、不过、然而、虽然……却、尽管……但是。
- 让步以假设为前提：即使……也、就算、哪怕、纵然。
- 对应关系：「但是」对应 pero（并列转折句）；「虽然」对应 aunque + 陈述式（事实让步）；「即使」对应 aunque + 虚拟式（假设让步）。

1. **转折复句**：
   - 可以译成转折句（pero、mas、sino、sin embargo、no obstante、con todo），也可以译成事实让步句（aunque、si bien、a pesar de que、pese a que、es cierto/verdad que…, pero…）。例：虽然去年水旱风灾大，但全国粮食仍然增产 → …y, sin embargo, … / A pesar de que…
   - 有时只能用一种：「不是……而是」→ No ha vendido el piso, sino que lo ha alquilado；「……确实不易，但是……更为困难」→ Es verdad que…; pero más difícil es…
   - 主语一致时可压成单句：
     - a pesar de、no obstante、pese a、si bien 加名词、不定式或形容词：麻雀虽小，肝胆俱全 → El gorrión tiene todas las vísceras a pesar de su pequeñez；中国虽然有九百六十万平方公里 → China, no obstante tener una superficie de…；事虽小，却极感人 → si bien sencillo, es conmovedor。
     - 副动词：荷花虽好，也要绿叶扶持 → Siendo tan bellas las flores de loto, …；我们虽是要好的朋友，见面的机会并不多 → Siendo muy amigos, pocas veces nos vemos。
2. **让步复句**：
   - aunque 或 así 加虚拟式：即便我愿意，我也无能为力 → Aunque quisiera, no lo podría intentar；哪怕是封建阶级和资产阶级的东西 → así sean estas obras de…
   - aun、incluso 加 cuando、si、en el caso de que：即使自己很正确，也要听听别人的意见 → Aun cuando tengas mucha razón…
   - 单句：aun、hasta、incluso 加名词：即使是地主，也可以变为农民 → Hasta los terratenientes… podrán…；即使是最好的东西，即使是马克思主义 → aun la mejor, aun el mismo marxismo。
3. **按实际意义判断事实还是假设，不看字面连词**：
   - 「有些人即使出身于工人农民家庭……」说的是事实，「即使」等于「虽然」→ a pesar de su origen obrero o campesino…
   - 「你参加革命时间虽然长，讲了错话，人家还是要驳」里的「你」是泛指，实为假设 → Si uno dice algo erróneo, la gente lo refutará, así tenga muchos años de militancia。

## 判断规则
- 无主句先分三类。泛指的才考虑 se、uno、quien；施事者不明的才用第三人称复数；表示「要、应该、必须」的用 hay que 或 es preciso。
- 「是」先问甲乙关系：同一、构成、意味、代表、内容、作用、结论，还是评论。
- 因果只取一个关联词；嫌啰嗦就压成「前置词＋名词」。
- 「虽然、即使」先按事实与假设判断，再定 aunque 后用陈述式还是虚拟式。

## 反模式
- 「是」一律译 ser，满篇 es…es…es。
- 把「因为……所以……」两个都译出。
- 「即使」一律用虚拟式，「虽然」一律用陈述式，不看实际意义。

## ↔ 西译中（反推）
- **西语泛指、无人称手段 → 汉语无主句**：
  - se incurriría en un craso error → 那就要犯大错误。
  - Quien no ha investigado no tiene derecho a opinar → 没有调查就没有发言权。
  - Hay que… / Es preciso… / Es indispensable… → 要……、应……、必须……
  - Ya han tocado el timbre → 已经打铃了。
  - **不要把 se 译成「人们」「有人」，不要把 uno 译成「一个人」**。动词变位隐含的主语，汉语多半不必补出。
- **西语多样的系动词 → 多半还原成「是」**：constituye、representa、supone → 是。只有意思真有差别时才保留：significa → 意味着、就是；radica en → 在于；sirve de → 起……的作用。He aquí / He ahí → 这就是；Se trata de… → 这是……
- **西语动词谓语 → 汉语「是……的」**：可以用来加强语气。Las dificultades son superables → 困难是可以克服的；Toda persona debe acatar la ley → 法律是人人必须遵守的。
- **因果**：
  - como、puesto que、ya que、dado que → 因为、由于、既然。
  - gracias a、debido a、a causa de + N → 由于、因为，或者干脆意合：Gracias a la producción, el personal mejoró… → 机关因为生产，工作人员生活改善了。
  - 后置的 porque 从句，汉语多半把原因提前：No debemos infringir… porque se trate de un viejo amigo → 不能因为是老朋友……就违反规定。
- **转折与让步**：
  - aunque + 陈述式 → 虽然；aunque + 虚拟式 → 即使、哪怕；así + 虚拟式 → 哪怕；aun cuando、incluso si → 即使；hasta、incluso + N → 连……也、即使是……
  - Es verdad que…, pero… → ……固然……，但……；si bien → 虽然。
  - **让步副动词要靠语境判断是因果还是让步**：Siendo muy amigos, pocas veces nos vemos 是让步，译「我们虽是好朋友，见面却不多」。
- 汉语关联词可以成对用（虽然……但是），但不要句句都加；能意合就意合。

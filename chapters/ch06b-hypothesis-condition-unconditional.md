# 第六章（中）句型：假设复句 · 条件复句 · 无条件句（原书 p.287–322）

## 核心
汉语分「如果」（假设）和「只要、只有」（条件）；西语一个 si 条件句就包括这两类。但西语必须区分现实假设（陈述式）和非现实假设（虚拟式过去时），汉语不分，译者要按事理判断。必备条件（只有……才）可用 sólo 加各种结构，或用 a menos que 加否定翻转。足够条件（只要……就）按语气强弱，从强到弱依次用 bastar、con tal que、si，持续条件用 mientras，一出现就生效的用 una vez、tan pronto como。无条件句（无论……都）在西语里是让步句，按选择式、是否式、疑问式分别处理。

## 框架
### 1. 假设复句（第五节）
1. **译成复句**：
   - 现实假设用 si + 陈述式：如果没有准备，就不要急于开会 → No hay que apresurarse a celebrar reuniones si no están bien preparados；如不消灭敌人，自己将被消灭 → Si uno no aniquila al enemigo, será aniquilado。
   - 非现实假设用 si + 虚拟式过去时：
     - 要是平日吃得好一点，他也不会得这种病 → Si de ordinario se hubiera alimentado un poco mejor, no habría contraído tal enfermedad。
     - 要不是靠钟先生关照 → Si no hubiera sido por la protección del Sr. Zhong…
     - 要是别人也用不关照来对待他们，那又会怎样？→ qué ocurriría si los demás también les trataran con desconsideración…
   - 其他连接词：en caso de que、caso (de) que、dado (el) caso (de) que。否定假设用 a menos que、a no ser que、salvo que，后面永远接虚拟式。
     - 你要是来不了，给我打个电话 → En caso de que no puedas venir, llámame。
     - 如果你们没什么需要的话，下午我就不来了 → No vendré esta tarde, a menos que me necesitéis para algo。
     - 你要是来了不帮忙，就别来 → No vengas, a menos que vengas a ayudar。
   - 假设可以看作主句的主语或宾语时，译成 que 名词从句或 quien 从句：
     - 如果到那时骄傲了，那就不好 → No sería bueno que, llegado ese momento, nos volviéramos arrogantes…
     - 如果不散会，所有的人都反对 → nos opondríamos a que esta reunión no se levantara…
     - 如果在行动上也站在革命人民方面，他就是一个完全的革命派 → Quien se coloca del lado del pueblo revolucionario… es un revolucionario completo。
2. **译成单句**：
   - de + inf.：如果不是这样 → De no haber sido así…
   - 副动词：如果只使用和从前相等的劳动 → trabajando como antes…
   - 名词或不定式作主语：如果采取消极态度，就会妨碍…… → Una actitud pasiva al respecto impediría…
   - sin 表否定假设：要是没有权威，就不会有社会 → Sin autoridad, no puede haber sociedad。
3. **「如果」等于「只要」时按条件句译**：
   - con tal que：如果我们这样做，胜利是我们的 → con tal que actuemos así…
   - mientras（已存在的情况持续下去）：如果小姊妹态度坚决，总罢工就可以继续 → Mientras las compañeras… se mantengan firmes…
   - cuando（一旦）：如果有问题，就要从个别中看出普遍性 → Cuando surge un problema…
4. **「如果」后是事实时，实为「如果说」**：可以不理「如果」（Después de que ustedes abandonaron…），也可以用 si 加完成时，这时的 si 同样不表示假设。

练习28 示例：
- 不是我跑得快 → De no haber huido yo…
- 如果说允许骄傲的话 → Si el engreimiento fuera algo permisible…
- 如果……那是很危险的 → Sería muy peligroso que no aprehendiéramos…
- 如果对形势认识不足，那就要犯大错误 → Quien no comprenda suficientemente esta situación… cometerá…
- 如果把同志当作敌人来对待，那就是…… → Tratar a los camaradas como a enemigos es…
- 我们如果不这样做（指过去），群众就会抬不起头来 → Si no hubiéramos obrado así, las masas populares no habrían podido levantar la cabeza。
- 如果说现在全国还有很多反革命分子，那是错误的 → Sería erróneo afirmar que…

### 2. 条件复句（第六节）
**必备条件「只有……才」「除非……否则」**，两种形式：
- a menos que、a no ser que、salvo que 加虚拟式，主句意思翻转：原文肯定，译文否定。
- 在表示假设的结构前加 sólo、únicamente：
  - sólo si：Sólo si permanecen en guardia… podrán… / no podrán…, a menos que permanezcan…
  - sólo + 副动词：只有破除了这些旧的观念，中国才有救 → Sólo destruyendo estas viejas creencias, China podrá salvarse。
  - sólo + 主语名词：只有实事求是，才能完成任务 → Únicamente el sentido práctico nos permitirá…；只有农业发展了…… → Sólo el desarrollo de la agricultura podrá asegurar…
  - sólo + 前置词短语：Únicamente sobre la base de…；Sólo después de consumado el primer proceso…
  - sólo cuando：只有……达到了预想的结果时，认识才被证实 → queda confirmado sólo cuando…

**足够条件「只要……就」**（语气由强到弱）：
1. bastar (con) + 条件 + para (que) + 结果（最强，条件相对容易做到）：只要有这点精神，就是一个高尚的人 → basta con que tenga este espíritu para que sea hombre de elevados sentimientos；只要说一声你认得我，保管没事 → basta decirles que me conoces para que no te molesten。
2. a condición de que、con tal (de) que、siempre que、siempre y cuando（适中）：只要我们有，前线要什么就给什么 → siempre que lo tengamos；只要依靠人民 → Siempre y cuando nos sustentemos en el pueblo。
3. si（结果不容易实现，或条件并非讲话人所愿）：只要工夫深，铁杵磨成针 → Hasta una barra puede convertirse en una aguja, si la pules con persistencia；只要对它们陷入盲目性，就可能成为包袱 → si las encaramos de manera ciega。
4. mientras（条件已是事实，只要它还存在）：只要小草的生命存在 → Mientras esté viva la hierba；只要还有一个人 → mientras quede un solo hombre。
5. tan pronto como、una vez que（条件一出现就……）：只要有可能 → tan pronto como sea posible；只要形成了这个统一战线 → Una vez establecido este frente único…

练习29 示例：只要政局上起点风潮，公债市场就受到影响 → El menor cambio en la situación política afectará inmediatamente las cotizaciones；只要船身晃一晃 → El más mínimo cabeceo de la barca bastaba para que…；这只要看一看认识的过程就会明了 → basta con mirar el proceso…

### 3. 无条件句（第七节）
汉语「无论、不论、不管……都、总、也」，西语属于让步主从复句。
1. **选择式（无论 A 还是 B）**：
   - 词语并列：y；tanto… como…；lo mismo… que…；否定句用 ni… ni…；o；(ya) sea… o…；trátese de… o de…
   - 例：无论在思想上、政治上、还是组织上 → Ideológica, política y organizativamente；无论是反攻或进攻 → Tanto en la contraofensiva como en la ofensiva；国家无论大小 → sean grandes o pequeños；不论陆军、空军和地方部队 → trátese de tropas terrestres, aéreas o…
   - 小句并列：(subj.)… o…；sea que… o que…；no/poco importa que…；independientemente de que…；lo mismo si (ind.)… que si…
   - 例：不论姓张姓李，是男是女，做工务农 → llámense Zhang o Li, sean hombres o mujeres, obreros o campesinos；无论是战争引起革命，还是革命制止战争 → Ya sea que… o que… / Poco importa que… / Lo mismo si… que si…
2. **是否式（无论是否）**：(subj.)… o no（Tengan conciencia o no de ello；Hayan estudiado o no…）；no importa si (ind.)；sin preocuparse de si (ind.)。
3. **疑问式**：
   - 无论什么＋名词：不强调时用 cada、cualquiera、todo、ninguno；无论何人 → todos、nadie；无论何时 → siempre、nunca（En ningún momento y en ninguna circunstancia debe un comunista…）。要强调「无论」，用 quienquiera que sea、sea quien sea、sea cual sea、trátese de quien se trate、no importa qué/quién sea、independientemente de quien sea：无论什么人，总要犯一些错误 → Toda persona, quienquiera que sea, inevitablemente comete errores。
   - 无论什么＋名词＋动词（副句）：
     - quien(quiera) que、cualquiera que、dondequiera que + subj.：Quien quiera conocer una cosa…；Dondequiera que aparezcan actividades criminales…
     - 动词虚拟式重叠：sea quien sea (fuere)、venga quien venga、pase lo que pase、vaya adonde vaya、provengan de donde provengan、encuéntrense donde se encuentren。
     - no/poco importa qué/cuál/quién/cuándo/dónde + subj.。
     - con independencia de / independientemente de + 名词。
   - 无论怎样＋动词：
     - 内容不论：Digan lo que digan y hagan lo que hagan；no importa qué/lo que；con independencia de lo que。
     - 方式不论：Córtala como la cortes；no importa cómo；independientemente de como。
     - 程度不论：por mucho que / por más que + subj.（不管我怎么说，他就是不相信 → Por mucho que se lo asegure, no me lo cree）。
   - 无论多么＋形容词：por + adj. + que + subj.（不管道路怎样迂回曲折 → Por sinuoso que sea el camino）；por muy/más + adj. + que；no importa cuán/qué + adj.；independientemente de cuán。
4. **「无论如何」「不管怎样」**（副词短语）：a toda costa、con todo、en todo caso、de ningún modo、en ninguna circunstancia；sea como sea、como quiera que sea；cueste lo que cueste、pase lo que pase、ocurra lo que ocurra。

练习30 示例：
- 这种语言，不管人们怎样称呼它 → Llámese como se llame。
- 不管听他说话的人满意不满意 → le gustara o no a su interlocutor。
- 适用的和不适用的，一起搬来 → copiarlo todo, sea o no aplicable…
- 不管它怎样说得好听 → por bonita que sea。
- 不管他怎么变 → por más que lo hiciera。
- 不管上面的石块如何重，石块之间如何狭 → no importa cuán pesadas sean las piedras de encima, ni qué finos sean los intersticios…

## 判断规则
- 「如果」先判断：现实还是非现实？是假设还是条件？是不是「如果说」（事实）？
- 「只有……才」用 sólo 正着说，或用 a menos que 反着说，二者选一。
- 「只要」看语气强弱和条件状态：容易做到用 bastar，一般用 siempre que，难以做到用 si，持续存在用 mientras，一出现就生效用 una vez。
- 「无论」先分选择式、是否式、疑问式；疑问式再分「什么、怎样、多么」。

## 反模式
- 所有「如果」一律用 si + 陈述式，反事实也不用虚拟式。
- 把「只要」和「只有」混用，强调点错了。
- 「无论」一律译 no importa，句式单调。

## ↔ 西译中（反推）
- **假设**：
  - si + 陈述式 → 如果……就。
  - si + 虚拟式过去时或过去完成时 → 要是……就……了、假如……的话；Si no hubiera sido por… → 要不是……
  - en caso de que → 万一、要是。
  - a menos que / a no ser que / salvo que → 除非……（否则），或改成正说：No vendré esta tarde, a menos que me necesitéis → 你们要是没什么事，下午我就不来了。
  - de + inf.（De no haber sido así）→ 要不是这样；sin + N（Sin autoridad, no puede haber sociedad）→ 没有权威，就不会有社会，汉语意合说法最自然。
  - 名词或不定式主语表假设：Una actitud pasiva impediría… → 如果采取消极态度，就会妨碍……
  - Sería muy peligroso que… → 如果……，那是很危险的，汉语把条件提到前面。
  - Quien no comprenda…, cometerá… → 如果对……认识不足，就会犯……
  - si 加完成时（如果说）→ 如果说……那么……
- **条件**：
  - Sólo si / sólo + 副动词 / únicamente + 名词、No… a menos que… → 只有……才……（翻回正说）。
  - Basta (con) que… para que… → 只要……就……；siempre que、con tal que、siempre y cuando → 只要……就……
  - mientras + 虚拟式 → 只要（还）……就……；Una vez + 分词、tan pronto como → 一旦……就……
  - El menor / el más mínimo + 名词 + 动词 → 只要……一……就……：El más mínimo cabeceo de la barca bastaba para que… → 只要船身晃一晃，他便……
- **无条件**：
  - sea quien sea、pase lo que pase、por mucho que、por + adj. + que、no importa qué/cómo/cuán、independientemente de、ya sea… o…、trátese de…、(subj.)… o no → 无论、不管、不论……都、也、总。
  - cueste lo que cueste → 无论如何、不惜一切代价；en todo caso → 不管怎样；de ningún modo → 无论如何不要、绝不。
  - **tanto… como…、lo mismo… que… 不一定是「无论」**，多数只是「A 和 B 都……」。
